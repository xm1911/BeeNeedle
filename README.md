# ビーニードル置き場
ご自由にお取りください

全てChrome/Chromium(Edge等)用の拡張機能です

基本的にA2とCをDLして頂ければ間違いないです

3種はそれぞれ役割が異なります
- A2は収集したログを使い完全一致で判定します
- 同様にMOD（MODと称しているが依存関係はない）はN-gramを使って高度な判定をします（スレ内のレス同士で比較する機能もあります）
- Cはログを扱わず現行スレッドのレス同士で完全一致判定するのと同時に悪用されやすい特殊な文字の検出も行います（Cはログサイト上で動作しません）
